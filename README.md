# repaso-python-ds
# Repaso de Python para Ciencia de Datos

## Descripción
Práctica de Python básico para aprender a manipular datos y prepararse para trabajar con librerías como Pandas y Scikit-Learn.

## Contenidos
- Variables y tipos de datos.
- Bucles y condicionales para clasificar precios.
- Diccionarios para administrar el stock de productos.
- Funciones para calcular suma, promedio y cantidad de elementos.

## Archivos
- `RepasoPython_McGrath.ipynb`: cuaderno de Google Colab.
- `analisis_basico.py`: código Python de la práctica.

## Objetivo
Consolidar los conocimientos básicos de Python aplicados al análisis de datos.
